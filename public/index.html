      Notes on values

      A note is shown in brackets next to a value wherever it appears (entries, outages, timeline, charts, filters). The log entries themselves stay unchanged; analysis, search, duplicate check and export ignore notes. Add one with ✎ next to a value in the tables.

        How Logalyzer calculates
        • Every log type describes how lines are split and which fields exist. View, filters and charts follow these fields.
        • If a log type has a state, an outage starts with a «down» value and ends with the next «up» value of the same object. Another «down» value in between is marked as «repeated».
        • Within the same minute «down» comes before «up», because the line order within a minute is often wrong. Recoveries without a preceding outage belong to an outage before the log starts.
        • The data is stored in the local MongoDB and does not leave the computer. On import, entries that are already stored are skipped.

          Copy the prompt, paste the reply
          1. Enter a name and a few sample lines (under 1.) – they are added to the prompt automatically.
          2. Copy the prompt and send it to Claude. Claude asks if needed and finally returns the schema as JSON.

          1. Sample

          Paste some lines of the log. For CSV with a header line or JSON lines, Logalyzer detects the columns itself. For text logs without columns choose the format «Text lines (regex)» below.

          2. Format and columns

          Tick = use the column. Exactly one field is called time and has the type Time. Fields without a source are filled by rules (below).

          ✓SourceField nameLabelTypeTime formatFilterChartTable

          3. State (optional)

          For logs in which an object goes down and comes back (connection lost / restored, CRITICAL / OK …). This produces the timeline, the outage table and findings.

          4. Rules and mappings (JSON, advanced)

          Rules derive further fields from a field (the first matching rule wins), mappings normalise values. See the README for the format. Claude can write these rules from a sample.
